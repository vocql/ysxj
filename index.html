Stream Setup Basics

Before mod tools matter, the stream itself has to run clean. This is the minimum viable setup checklist — encoding, bitrate, and audio.

Pick your encoder

Use x264 (CPU) if your CPU has headroom, or NVENC/AMF (GPU) if you're gaming and streaming on the same machine. GPU encoding costs less FPS in the game itself.

Set your bitrate

Twitch caps at roughly 8000 Kbps (6000 recommended for most). YouTube supports much higher, up to 51 Mbps at 4K, but 4500–9000 Kbps at 1080p60 is a common sweet spot. Match bitrate to your actual upload speed and test it before going live.

Resolution & framerate

1920×1080 at 60fps is standard for action or gameplay content. 1080p30 or 720p60 works fine on limited upload. Keep output resolution at or below canvas resolution.

Audio routing

Separate tracks for mic, desktop audio, and game audio using an audio mixer or OBS's multi-track output. Target -12dB to -6dB average on mic, with a noise gate and compressor filter chain.

Scene & source hygiene

Use descriptive scene names (Starting Soon / Live — Gameplay / BRB / Ending). Nest sources in groups and lock anything you don't move mid-stream to avoid mis-clicks.

Protect your stream key

Never show it on screen and never paste it in Discord. Regenerate it immediately if it leaks, and use OBS's hide toggle on the stream key field whenever you're screen-sharing setup.

Twitch Mod Tools

What a Twitch moderator can do, and how it's actually used during a live chat.

Moderator Role /mod

Grant with /mod username, remove with /unmod username. Mods get a sword icon, access to the Mod View, and the chat commands below. Mod status doesn't carry between channels.

AutoMod

Twitch's built-in filter that holds flagged messages — hate speech, sexual content, profanity, spam — for mod review before they post. Sensitivity is adjustable per category in Creator Dashboard → Moderation → AutoMod.

Shield Mode

One-click lockdown for raids or hate-raids: auto-enables follower-only chat, emote-only, and stricter AutoMod. Toggle from the Mod View or with /shieldmode.

VIP Role /vip

Non-moderation badge for trusted community members — bypasses slow mode and sub-only mode but carries no moderation powers. Grant with /vip username.

YouTube Mod Tools

YouTube Live's moderation model is chat-first — most actions happen from the live chat panel itself.

Adding Moderators

Click a viewer's name in live chat and select "Add moderator," or go to YouTube Studio → Live Control Room → Live Chat and add by channel or handle before you go live.

Blocked Words List

Studio → Settings → Community → Automated filters. Messages containing listed terms are auto-held for review instead of posting immediately.

Slow Mode

Live chat gear icon → set a cooldown of 5 to 30+ seconds between messages per user. Reduces spam without banning anyone.

Members-Only Chat

Restrict live chat to Channel Members only during high-traffic or high-risk streams — useful during raids or controversial topics.

Discord Mod Tools

The VOQCL server runs on a mix of native Discord permissions and Leonida Bot automation. This is the baseline every mod should know before touching a role.

Roles & Permissions

Discord permissions are additive and role-order matters — a role can only manage roles positioned below it. Keep Moderator below Admin, above Member, and never grant Administrator to a role used day-to-day.

Timeouts vs. Kicks vs. Bans

Timeout mutes a member server-wide for a set duration without removing them — the first move for most incidents. Kick removes them but allows rejoining. Ban removes and blocks rejoining unless reversed.

AutoMod (Discord native)

Server Settings → Safety Setup → AutoMod. Blocks messages by keyword list, mention-spam thresholds, and known scam-link patterns before they ever post — independent of any bot.

Verification & Gating

Server Settings → Safety Setup → Verification Level, plus rule-acknowledgment gates or captcha screening for new joins. Raises the bar before a new account can post in chat.

Audit Log

Server Settings → Audit Log records every mod action — bans, kicks, role changes, channel edits — with who did it and when. Check it first when a decision gets questioned.

Join-to-Create & Ticket Tools

Leonida Bot handles voice channel creation on join and a ticket system for support requests — both reduce the number of things that need a human mod watching at all times.

Chat Bot Documentation

Streamlabs, Nightbot, and StreamElements all do custom commands, timers, and moderation automation — but each has a different config model. Pick one to own chat commands; don't run two bots answering the same trigger.

PlatformsTwitch, YouTube (Cloudbot)
Setupstreamlabs.com → Cloudbot tab, no separate site login needed
Best forStreamers already using Streamlabs OBS or desktop app for alerts

Cloudbot Modules

Loyalty points, giveaways, song requests, quotes, polls, mini-games (roulette, duel, slots), and a full moderation module — each toggled independently in the dashboard.

Custom Commands

Built with a variable system ($(user), $(count), $(touser)) plus permission levels — Everyone, Regular, Subscriber, Moderator, Owner — and per-command cooldowns.

Alerts Integration

Since it's the same company as Streamlabs alert boxes, Cloudbot commands can trigger on-screen alerts directly — no separate webhook wiring needed.

PlatformsTwitch, YouTube
Setupnightbot.tv → log in with platform account, invite bot to channel
Best forFast, lightweight command and timer management with a clean web dashboard

Commands

Add via dashboard or in-chat with !commands add. Supports the same style of variables — $(user), $(1) for arguments, $(urlfetch) for pulling external API data into a response.

Timers

Rotate a set of messages automatically every X minutes, with a minimum chat-line threshold so it doesn't fire into a dead chat. Good for socials, schedule, and rules reminders.

Spam Protection

Built-in filters for links, caps, symbols, emotes, and walls of text — each with its own sensitivity slider and punishment tier (delete → timeout → ban) independent of platform AutoMod.

Loyalty System

Channel currency earned per minute watched, redeemable via chat commands for perks you define — timeouts on friends, song skips, custom raffle entries, and more.

Same variable-driven command builder (${user}, ${touser}, ${1}) with global and per-user cooldowns and permission tiers.

Overlay + Bot Combo

Because StreamElements also runs the overlay and alert layer, bot events like new followers or loyalty redemptions can drive on-stream widgets without extra integration work.

Mod Role Cheat Sheet

Quick reference for who can do what — hand this straight to a new mod.

New Mod, First Stream

  • Learn the timeout/ban commands before anything else
  • Know the channel's actual rules, not just "don't be a jerk"
  • Ask where the banned-words list lives and read it
  • Confirm who to ping for a ban appeal or escalation

During a Raid

  • Enable Shield Mode (Twitch) or slow/members-only (YouTube)
  • Watch for copy-paste spam and coordinated slurs
  • Ban, don't just timeout, on hate-raid accounts
  • Communicate with co-mods in the Discord mod channel

Bot Command Hygiene

  • Only one bot should own a given command — no duplicate !discord across two bots
  • Set cooldowns on anything that can be spammed
  • Review the custom command list monthly, prune dead ones
  • Lock loyalty-point redemptions that affect other viewers behind mod approval

Glossary

Terms you'll hear thrown around in mod chat and streaming Discords.

AutoMod

The automatic message filter — on Twitch, YouTube, or Discord — that holds risky messages for review before posting.

Hate Raid

Coordinated bot-driven raid meant to flood chat with harassment or slurs, usually via fake or throwaway accounts.

Shield Mode

Twitch's one-click chat lockdown for raids — tightens AutoMod and chat modes instantly.

Loyalty Points

Bot-tracked currency earned by watching, spent on chat-triggered perks you configure.

Sub-only / Follower-only Mode

Chat modes restricting who can type based on subscription status or follow age.

Bitrate

How much data the stream sends per second — the main lever for stream quality versus upload bandwidth.
