what it does

Nine systems. One tag.

Every feature runs per-server, stacks with hardcoded fallbacks, and gets saved to disk — nothing resets when the bot restarts.

01 🛠️

Core Moderation

Kick, ban, softban, massban, tempban, timeout, warn, and private mod notes — every action requires the matching Discord permission.

02 📁

Case History

Every mod action gets a numbered case automatically. Pull a member's full record with /cases, or one case by number with /case.

03 🔑

Access Control

Each server picks which roles can use the bot at all — server owners always have access, even before a role is set.

04 🍯

Honeypot Trap

Turn a channel into bait. Anyone who posts there is instantly soft-banned — one shot, no warning, and it's logged.

05 🚫

Media / Link Lock

Flip a switch and only GIFs get through — everything else is deleted on sight. Exemptions stack across three separate allowlists.

06 🌴

GTA VI Countdown

One message per channel, edited in place every five minutes — a live clock and a progress bar counting down to November 19, 2026.

07 👋

Welcome Tags

New members get a custom embed with their avatar, the server banner, and a message you write yourself with live placeholders.

08 📋

Logging & Snipe

Edits, deletions, and mod actions land in as many log channels as you want. Deleted images get reposted before Discord kills the link.

09 🔧

Utility & Info

Server info, user lookups, avatars, ban lists, and a full dropdown /help menu for anyone who needs the map.

get it running

Up on the wall in four

The bot is invisible in the member list by design — it's working the whole time, it just doesn't need to be seen doing it.

STEP 1

Invite the bot

Hit "Add to Server" up top. It asks for Administrator so every moderation action actually works — no partial permissions to debug later.

STEP 2

Set an allowed role

Run /addallowedrole and pick your mod/admin role. Until you do, only the server owner can run commands.

STEP 3

Wire up logging

Add a channel with /addmodlog and /addimagelog so every case, edit, and deletion has somewhere to land.

STEP 4

Turn on what you need

Welcome channels, a honeypot, the media lock, the GTA VI countdown — all optional, all one slash command away.

how permissions stack

Nothing overrides, everything stacks

Server settings, hardcoded fallbacks, and text-file allowlists never fight each other — being on any one list is always enough.

Who's exempt from what

Command access, the media lock, and log/welcome/countdown channels are each controlled by up to three sources at once. Any single match is enough — nothing needs to agree with anything else:

  • Per-server slash commands — /addallowedrole, /medialockallowuser, /addmodlog, and friends. Take effect immediately, no restart.
  • Hardcoded fallback lists — built into the bot for its original servers, so they keep working with zero setup.
  • Text files next to the bot — edit a plain .txt file, one ID per line, and it's picked up on the next relevant event.

Not sure if someone's exempt from the media lock right now? /checkmedialockexempt tells you exactly which rule matched — no digging through console logs.
